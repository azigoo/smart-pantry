Este índice organiza toda la documentación generada durante el desarrollo, siguiendo
la rúbrica de "Administración de la calidad de software". Los puntos 1 a 4 están en el
documento original de planificación, análisis de requisitos y diseño (PDF entregado
aparte); a partir de este repositorio se documentan los puntos de implementación en
adelante.

**Nota importante:** los puntos 5 a 8 se escribieron documentando honestamente lo que
sí se hizo y lo que quedó pendiente en cada corte del proyecto (por ejemplo, cuando no
existía todavía la conexión a Firebase). Para no reescribir la historia, esos archivos
**no se actualizaron retroactivamente** al agregar Firebase; el estado más reciente del
proyecto (con autenticación real) está reflejado en `CHANGELOG.md` y en este mismo
índice.
